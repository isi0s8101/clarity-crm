# Matrice de traçabilité — fermeture `clarity-crm_v0.3`

Source de vérité : runtime POSIX Next.js/Node.js 22 + PostgreSQL 17. Cloudflare D1/Wrangler est uniquement une source legacy d'import ; une ancienne recette D1 ne valide aucune ligne PostgreSQL.

Statuts : `VALIDÉ_POSTGRESQL`, `IMPLÉMENTÉ_NON_VALIDÉ`, `PARTIEL`, `BACKEND_SEUL`, `UI_SEULE`, `LEGACY_D1`, `NON_IMPLÉMENTÉ`.

Une ligne est `VALIDÉ_POSTGRESQL` uniquement lorsque la chaîne exigence → code → test → preuve est complète. Les preuves CI désignent le job GitHub `verify-posix` de `.github/workflows/ci.yml`.

## Décision de fermeture

`clarity-crm_v0.3` est fermé lorsque le commit contenant cette matrice obtient une CI `verify-posix` verte. Les fonctions v1.1, v1.2, v1.3, v2.1, v2.2 et v2.3 ne font pas partie de ce lot et ne sont pas commencées ici.
