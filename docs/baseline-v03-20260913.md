## Reproduction depuis un clone propre

Prérequis : Linux/POSIX, Node.js 22.13+, npm, PostgreSQL 17, `psql`, `pg_dump`, `pg_restore`, `curl`, `jq`, Python 3 et SQLite pour la recette legacy.

```bash
git clone https://github.com/isi0s8101/clarity-crm.git
cd clarity-crm
git checkout baseline-technique-depart-v0.3-20260913
npm ci
npm run lint
npm test
npx tsc --noEmit
NODE_ENV=production npm run build
npm run db:migrate
npm run bootstrap:admin
NODE_ENV=production bash scripts/ci-e2e-posix.sh
bash scripts/ci-legacy-d1-migration.sh
bash scripts/ci-backup-restore-postgres.sh
```

Variables requises : `DATABASE_URL`, `CLARITY_ADMIN_EMAIL`, `CLARITY_ADMIN_PASSWORD`, `CLARITY_COOKIE_SECURE=0` uniquement pour les recettes HTTP locales.
